# Politique de sécurité — Scoolize

## Signaler une vulnérabilité

Si vous découvrez une faille de sécurité dans Scoolize, merci de nous la signaler de manière responsable.

- **Email** : security@scoolize.local
- **PGP** (optionnel) : disponible sur demande
- **Délai d'accusé de réception** : 24h ouvrées

Nous nous engageons à :
- ne prendre aucune mesure juridique contre les chercheurs agissant de bonne foi (safe harbor)
- vous tenir informé de la progression de la correction
- reconnaître publiquement votre contribution (si vous le souhaitez)

Merci de ne pas :
- exploiter la vulnérabilité au-delà du strict nécessaire à sa démonstration
- divulguer publiquement la faille avant correction (délai raisonnable : 90 jours)
- accéder à, modifier ou supprimer des données d'autres utilisateurs

## Périmètre

Toutes les surfaces exposées publiquement sont dans le périmètre, notamment :
- scoolize.local et ses sous-domaines
- API publiques
- Applications mobiles / extensions

Hors périmètre :
- Attaques nécessitant un accès physique
- Ingénierie sociale contre nos employés
- Vulnérabilités connues des dépendances déjà planifiées (voir Dependabot)
